## スマートフォン連携

Windows の「スマートフォン連携」のように、PC のブラウザと Android をつなぐアプリです。

**Web（PC側）:** https://smartphone-renkei.vercel.app

### 使い方
1. **SmartphoneRenkei-v*.apk** をダウンロードしてインストール（Android 10 以上）
2. PC で https://smartphone-renkei.vercel.app を開く
3. アプリの「QRコードをスキャン」でPCのQRを読み取る
4. 設定タブで通知・SMS・通話履歴・写真などの権限を許可

### 機能
ファイル送受信 / クリップボード同期 / 通知ミラー / SMS 閲覧・送信 / 通話履歴・PCから発信 / 写真の取り込み / スマホを鳴らす / リンク送信 / 共有メニューからPCへ送信 / ダイナミックカラー
